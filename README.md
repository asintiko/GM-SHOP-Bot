# GM SHOP Bot

Telegram-бот для магазина GM SHOP с функциями модерации, конкурсов и управления сообществом.

## Возможности

### Модерация
- Автоматический антифлуд (6+ сообщений подряд → мут 50 минут)
- Фильтры спама, казино, рекламы заработка
- Команды модерации: `/ban`, `/mute`, `/warn`, `/kick`
- Поддержка русских команд: `!бан`, `!мут`, `!варн`
- Гибкий парсер времени: `50м`, `3ч`, `2д`, `1w`, `1h30m`

### Система кармы
- Автоматическое начисление/снятие кармы через ключевые слова
- Защита от фарма (кулдауны)
- Команда `/karma` для просмотра

### Еженедельные топы
- Автоматическая публикация топ-3 активных участников
- Настраиваемая формула расчёта очков
- Призы для победителей

### Конкурсы/Розыгрыши
- Создание и управление через ЛС бота
- Автоматический выбор победителей
- Защита от накрутки

### Система браков
- Игровая социальная механика
- Команды: `/marry`, `/accept`, `/decline`, `/divorce`, `/couple`

### Управление
- Все настройки через ЛС с ботом
- Редактируемые тексты приветствия и правил
- Гибкая настройка фильтров и порогов

## Технологический стек

- **Python 3.11+**
- **aiogram 3.x** - Telegram Bot framework
- **PostgreSQL 15** - основная БД
- **Redis 7** - кэш и очереди
- **Docker & docker-compose** - контейнеризация
- **APScheduler** - планировщик задач
- **structlog** - структурированное логирование

## Быстрый старт

### Требования

- Docker и docker-compose
- Telegram Bot Token (от @BotFather)

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd GMshop
```

2. **Создайте .env файл:**
```bash
cp .env.example .env
```

3. **Отредактируйте .env файл:**
```env
# Получите токен от @BotFather
BOT_TOKEN=your_bot_token_here

# Укажите ваш Telegram ID (можно узнать у @userinfobot)
OWNER_IDS=123456789

# ID канала для логов (создайте приватный канал и добавьте бота админом)
ADMIN_LOG_CHAT_ID=-1001234567890
```

4. **Запустите бота:**
```bash
docker-compose up -d
```

5. **Проверьте логи:**
```bash
docker-compose logs -f bot
```

## Настройка

### Добавление бота в группу

1. Добавьте бота в вашу группу
2. Сделайте бота **администратором** с правами:
   - Удаление сообщений
   - Ограничение участников
   - Управление сообщениями (опционально)
3. **Важно:** Отключите режим приватности у бота (Privacy Mode = disabled в @BotFather)

### Настройка через ЛС

1. Напишите боту в личку `/start`
2. Используйте меню для настройки:
   - Приветствие
   - Правила
   - Антифлуд
   - Фильтры
   - Карма
   - Топ недели
   - Конкурсы
   - Браки

## Команды

### Для пользователей
- `/rules` - Показать правила чата
- `/karma [@user]` - Посмотреть карму
- `/profile` - Показать профиль
- `/top` - Показать топ недели
- `/marry @user` - Предложить брак
- `/accept` / `/decline` - Принять/отклонить предложение
- `/divorce` - Развестись
- `/couple` - Показать пару

### Для модераторов
- `/ban @user [время] [причина]` - Забанить пользователя
- `/mute @user <время> [причина]` - Замутить пользователя
- `/warn @user [причина]` - Выдать предупреждение
- `/kick @user [причина]` - Кикнуть пользователя
- `/unban @user` - Разбанить
- `/unmute @user` - Размутить
- `/unwarn @user` - Снять предупреждения

Также поддерживаются команды с `!`: `!бан`, `!мут`, `!варн`, `!кик`

## Разработка

### Локальная разработка без Docker

1. **Создайте виртуальное окружение:**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Запустите PostgreSQL и Redis локально**

4. **Обновите DATABASE_URL и REDIS_URL в .env**

5. **Примените миграции:**
```bash
psql -U your_user -d gmshop -f migrations/001_init_schema.sql
```

6. **Запустите бота:**
```bash
python -m bot.main
```

### Тестирование парсера времени

```bash
python bot/utils/time_parser.py
```

### Тестирование фильтров

```bash
python bot/utils/filters.py
```

## База данных

Схема БД автоматически создаётся при первом запуске через Docker.

Основные таблицы:
- `chats` - информация о чатах
- `users` - пользователи
- `chat_members` - статистика участников
- `sanctions` - история санкций
- `karma_events` - события кармы
- `giveaways` - конкурсы
- `marriages` - браки
- `staff` - админы/модераторы

## Логи

Логи сохраняются в:
- `logs/` директория (монтируется в Docker)
- Stdout (структурированный JSON)
- Админ-канал (для важных событий)

Просмотр логов:
```bash
docker-compose logs -f bot
```

## Безопасность

- Все токены и ключи в `.env` (не коммитить!)
- Параметризованные SQL-запросы (защита от инъекций)
- Проверка прав на каждую команду модерации
- Минимальное хранение персональных данных
