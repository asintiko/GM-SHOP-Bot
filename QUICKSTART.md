# GM SHOP Bot - Быстрый старт

## ✅ Что уже сделано:

Проект полностью готов к запуску! Реализовано:

### Основной функционал:
- ✅ Антифлуд (6+ сообщений → мут 50 минут)
- ✅ Фильтры спама (казино, заработок, реклама)
- ✅ Система кармы с кулдаунами
- ✅ Еженедельные топы с автопубликацией
- ✅ Система браков (игровая механика)
- ✅ Приветствие новых участников
- ✅ Команды модерации (/ban, /mute, /warn, /kick)
- ✅ Админ-панель через ЛС

### Техническая часть:
- ✅ PostgreSQL база данных (12 таблиц)
- ✅ Redis для кэша
- ✅ Docker + docker-compose
- ✅ APScheduler для задач по расписанию
- ✅ Структурированное логирование
- ✅ Middleware для проверки прав

## 🚀 Запуск бота

### Способ 1: Через Docker (рекомендуется)

1. **Запустите Docker Desktop**

2. **Запустите бота:**
```bash
./start.sh
```

Или вручную:
```bash
docker-compose up --build -d
```

3. **Проверьте логи:**
```bash
docker-compose logs -f bot
```

### Способ 2: Локальный запуск (для разработки)

1. **Установите PostgreSQL и Redis локально**

2. **Создайте базу данных:**
```bash
createdb gmshop
psql gmshop < migrations/001_init_schema.sql
```

3. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

4. **Обновите .env:**
```env
DATABASE_URL=postgresql://localhost:5432/gmshop
REDIS_URL=redis://localhost:6379/0
```

5. **Запустите бота:**
```bash
python -m bot.main
```

## 📱 Первые шаги

### 1. Проверьте что бот работает

Вы должны получить сообщение в Telegram от бота:
```
🤖 GM SHOP Bot запущен!

Бот успешно подключился к базе данных и готов к работе.
```

### 2. Добавьте бота в группу

1. Добавьте бота в вашу группу
2. Сделайте его **администратором** с правами:
   - ✅ Удаление сообщений
   - ✅ Ограничение участников
   - ✅ Управление сообщениями (опционально)

3. **Важно!** Отключите режим приватности:
   - Зайдите к @BotFather
   - /mybots → выберите вашего бота
   - Bot Settings → Group Privacy
   - **Turn OFF** privacy mode

### 3. Протестируйте команды

**В группе:**
```
/rules - Покажет правила
/karma - Ваша карма
/profile - Ваш профиль
```

**В ЛС с ботом:**
```
/start - Админ-панель
/menu - Показать меню настроек
```

**Модерация (для админов):**
```
/ban @user 1д спам
/mute @user 50м флуд
/warn @user нарушение
```

### 4. Проверьте автомодерацию

**Антифлуд:**
- Отправьте 6 сообщений подряд быстро
- Бот должен выдать мут на 50 минут

**Фильтр спама:**
- Напишите: "заработок без вложений"
- Сообщение будет удалено, пользователь замучен

**Карма:**
- Ответьте на чье-то сообщение со словом "спасибо"
- Пользователь получит +1 к карме

## 📊 Структура команд

### Для всех пользователей:
- `/rules` - Правила чата
- `/karma [@user]` - Посмотреть карму
- `/profile` - Показать профиль
- `/top` - Топ недели
- `/marry @user` - Предложить брак
- `/accept` / `/decline` - Принять/отклонить
- `/divorce` - Развестись
- `/couple` - Показать пару

### Для модераторов:
- `/ban @user [время] [причина]`
- `/mute @user <время> [причина]`
- `/warn @user [причина]`
- `/kick @user [причина]`
- `/unban @user`
- `/unmute @user`

Также: `!бан`, `!мут`, `!варн`, `!кик`

### Формат времени:
- `50м` - 50 минут
- `3ч` - 3 часа
- `2д` - 2 дня
- `1w` - 1 неделя
- `1h30m` - 1.5 часа

## 🔧 Управление

### Просмотр логов:
```bash
docker-compose logs -f bot
```

### Остановка:
```bash
docker-compose down
```

### Перезапуск:
```bash
docker-compose restart bot
```

### Бэкап базы:
```bash
docker-compose exec postgres pg_dump -U gmshop_user gmshop > backup_$(date +%Y%m%d).sql
```

### Восстановление:
```bash
cat backup.sql | docker-compose exec -T postgres psql -U gmshop_user gmshop
```

## 🐛 Решение проблем

### Бот не отвечает в группе:
- Проверьте что бот админ
- Проверьте что Privacy Mode выключен

### Бот не запускается:
```bash
# Проверьте логи
docker-compose logs bot

# Проверьте подключение к БД
docker-compose exec postgres psql -U gmshop_user -d gmshop -c "SELECT 1"
```

### Ошибка подключения к БД:
```bash
# Пересоздайте базу
docker-compose down -v
docker-compose up -d
```
